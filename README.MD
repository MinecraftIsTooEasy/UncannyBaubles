# Uncanny Baubles Mod for MITE (FML-3.X)

## Features

Uncanny Baubles adds a variety of baubles with strange and unusual powers to MITE.

## Credits

The Magnet, Pocket Piston, Lucky Clover, and Bottled Cloud in this mod are based on GA-Higher's designs.

Most other baubles are inspired by Terraria, with some also ported from Artifacts.
